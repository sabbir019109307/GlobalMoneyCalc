Privacy Policy

Last updated: November 23, 2026

GlobalMoneyCalc provides browser-based calculators for general information.

Calculator data

Values entered into the calculators are processed in your browser. The current version has no user accounts and does not send calculator entries to a GlobalMoneyCalc database.

Hosting

This website is hosted using GitHub Pages. The hosting provider may process technical information such as request logs, IP addresses and browser details to operate and secure the service. Please review GitHub's privacy statement for details.

Cookies and advertising

The current version does not intentionally set advertising cookies or include third-party advertising scripts. If analytics or advertising services are added later, this policy will be updated to describe them.

External links

Third-party websites have their own privacy practices and policies.

Contact

For now, raise privacy questions through the project GitHub issue page. Do not include sensitive personal information in a public issue.
